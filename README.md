# Vibe Coding Tools

[English](#english) | [中文](#中文)

## English

Two small tools for vibe coding with AI agents, each in its own folder:

| Folder | What it does | Platforms |
|---|---|---|
| [`presenter/`](presenter/) | **Vibe Coding Presenter.** Turns a wireless presenter remote into a voice controller: double-press to start or stop dictation, double-press to send. | Windows (ChatGPT, Codex, Claude, PRISM), macOS (Claude) |
| [`session-manager/`](session-manager/) | **Session Manager.** A Claude Code skill that makes one Claude Desktop session the manager of all the others: it shows you the session that has waited longest and relays your reply to it word for word. | Windows, macOS |

Each folder has its own README with installation and usage.

## 中文

两个配合 AI agent 做 vibe coding 的小工具，各放在一个文件夹里：

| 文件夹 | 做什么 | 平台 |
|---|---|---|
| [`presenter/`](presenter/) | **激光笔控制（Vibe Coding Presenter）**：把无线激光笔变成语音控制器，双击开始或停止语音输入，双击发送。 | Windows（ChatGPT、Codex、Claude、PRISM）、macOS（Claude） |
| [`session-manager/`](session-manager/) | **会话管理（Session Manager）**：一个 Claude Code 技能，让一个 Claude Desktop 会话管理其他所有会话：把等得最久的会话拿给你看，你的回复原话转过去。 | Windows、macOS |

安装和用法见各文件夹里的 README。
